# **Dinosaur Settlement**

## Purpose of creation
A project completed as part of a course at the Yandex Academy Lyceum. My first experience creating a game using Pygame.

## **About the game**
A game about a cute dinosaur who lives on an island with a cat.

### **The goal of the game**
Earn a certain amount of coins to move to a new level and then complete the game.

### **When the game ends**
The game ends when the required number of coins is reached on the last level.

### **Ways to earn coins**
* Collecting crystals
* Destroying objects
* Purchasing houses that earn coins
* Completing tasks from the cat
